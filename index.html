Tetrish

A no-timer packing puzzle. Fill every square.

Controls

Status

Tap a piece to select it. Drag it to move. Let go to place it if it fits.
Phone: tap to select, drag to move, release to place if it fits. Keyboard: Q/R/E rotate, H hold, Enter place, N new puzzle.

How it works

Every puzzle uses a prebuilt piece set that is guaranteed to tile the board completely. The order is shuffled each round, so the solution is always possible but not always obvious.

Rules

Tap any piece to select it. Drag a selected piece onto the grid. If you let go and it fits, it places automatically. If it does not fit, it keeps hovering until you drag it somewhere that does. A green outline fits. A red outline does not. The hold slot stores one piece and can be swapped at any time.
