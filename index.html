Fill Grid

A no-timer packing puzzle. Fill every square.

Controls

Status

Pick up the current piece and place it on the board.
Keyboard: Q/R/E rotate, H hold, Enter place, N new puzzle.

How it works

Every puzzle uses a prebuilt piece set that is guaranteed to tile the board completely. The order is shuffled each round, so the solution is always possible but not always obvious.

Rules

Click any piece to select it. Drag a selected piece over the grid to snap it into position, rotate it if needed, then place it when you are happy with the fit. The hold slot stores one piece and can also take a placed piece.
